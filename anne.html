Open Cognitive Architecture for Heterogeneous AI Systems

Adaptive Neural Nexus Engine (ANNE)

ANNE is an open cognitive architecture designed to coordinate, evaluate, learn from, structure and reuse the outputs of heterogeneous AI systems.

It is a research platform — not a chatbot product, not a foundation model, and not an AGI claim.

Intelligence is not only prediction. Intelligence is the recursive organization of relationships.

Problem

  • Models are often used in isolation
  • Outputs remain ephemeral
  • Systematic comparison across systems is weak
  • Prior work is hard to reuse as structured knowledge
  • Model suggestions must not equal real-world authority

ANNE investigates whether an explicit cognitive orchestration layer can improve reliability, traceability and controllability of model-assisted reasoning.

Architecture (conceptual loop)

User / Task→ ANNE→ Decomposition→ MITOS→ Heterogeneous AI→ Evaluation→ Cognitive Memory→ Executive→ Agency Gate→ Output

Implemented cognitive stages in the broader platform:

DUY→BAK→GÖR→ANLA→HİSSET→YAP

This is not only a one-shot linear pipeline: validated or failed states can re-enter under bounded budgets (see Fractal / Re-entrant Reasoning).

Neuro-symbolic Approach

Technical term in the repository: neuro-symbolic (not “neuro-symbiotic” as an architecture name).

Neural side

  • Language models
  • Local / offline models
  • API-based models
  • Probabilistic generation

Symbolic / control side

  • Semantic validation (ANLA)
  • Contradiction handling
  • Evidence & provenance
  • Reasoning audit
  • Ethical constraints
  • Plan verification
  • Safety gates / Agency Gate

ANNE does not treat the language model as the sole authority. Probabilistic generation is combined with explicit evaluation, evidence, contradiction handling, memory and bounded action control.

MITOS — discovery & exploration layer

MITOS is not merely a task decomposer. In the research architecture it supports exploration: alternatives, comparison, hypothesis-oriented candidates, and process management for the discovery side of cognition.

IMPLEMENTED core process pieces · EXPERIMENTAL swarm / deeper multi-agent paths.

Constitutional rule: MITOS generates ideas; it does not possess external agency.

Cognitive Memory

Persistent / fractal memory stores structured cognitive material (hypotheses, decisions, patterns, failure traces) — not raw chat history.

Memory ≠ Learning. Claiming “learning” requires measurable behavioural change — not storage alone.

Fractal / Re-entrant Reasoning

Bounded re-entrant mechanism: validated or failed reasoning states can become structured inputs for subsequent cycles — not unrestricted recursive intelligence.

IMPLEMENTED BOUNDED

Executive ANNE

Synthesises from evaluated cognitive structure and process results — not a pass-through wrapper that only echoes a single model string.

Agency Gate & safety architecture

Inference ≠ Authority. Silence is not consent. Model output alone is not permission for external side effects.

  • AgencyGate (default-deny for external actions)
  • Allowlisted tools; empty allowlist denies tools
  • Evidence, contradiction handling, provenance
  • Safety > Optimization

ANNE does not claim “fully safe” or “safety solved”.

Related portfolio — EDCS

EDCS (Emergent Drone Coordination System) is a distributed, self-healing drone swarm coordination project in the same Vitavolt research portfolio as ANNE: ethical and autonomous systems, without central command dependence. Target environments include weak/denied GPS and intermittent links.

Status: architecture and mathematical model complete · simulation prototype running · hardware / UWB / field trials planned. Not a field-deployed product claim.
